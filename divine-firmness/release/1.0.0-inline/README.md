Eleven numbered sections for Ecwid Instant Site custom code (each under 19,900 characters). Paste in order 01 to 11 into eleven separate Custom code blocks on the firmness page.

01 CSS module, 02 CSS visual, 03 Markup intro and scene, 04 Zone explanations (texts and panel style), 05 Markup module and AI layer (JSON-LD), 06 Markup sketches (too firm, too soft, correct, at the bottom of the page), 07 Logic engine, 08 JS module, 09 JS visual, 10 Font 400, 11 Font 600.

Everything is inline. The only external file is the model photo (needs an Ecwid-hosted URL, see section 3). No phone numbers. Contact is email only.

Home page (divinedunlop.com): section 1 is not touched. Add the one block in release/1.0.0-home/01_home_teaser.html as section 2. Fine-Tuning carries the full module, so the home page stays light and Google indexes the module once.
