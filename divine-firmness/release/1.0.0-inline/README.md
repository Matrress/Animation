# Divine Firmness Navigator, inline release 1.0.0

Twelve numbered sections for Ecwid Instant Site custom code (each under 19,900 characters). Paste in order 01 to 12 into twelve separate Custom code blocks on the firmness page. Do not mix the numbers up: the section number is the file number.

01 CSS module, 02 CSS visual, 03 Markup intro and scene, 04 Zone texts, panel style and the one-screen layout (also holds the page check), 05 Markup module and AI layer (JSON-LD), 06 Markup sketches (too firm, too soft, correct, sitting and lying), 07 Markup weight distribution (the same 70 kg, distributed or concentrated), 08 Logic engine, 09 JS module, 10 JS visual, 11 Font 400, 12 Font 600.

Everything is inline. The only external files are images: the model photo and the Partners picture from pinned jsDelivr commits, and the site logo from the site's own Ecwid CDN. No phone numbers. Contact is email only (support@divinedunlop.com).

Page check: add `#dn-chk` to the page address. A banner shows `3 scene | 4 style | 5 module | 8 engine | 9 script | 10 script`, each OK or MISSING. The numbers are the section numbers.

Section 07 uses the heading class from section 06 and the colour variables from section 01, so keep 01 and 06 on the page.

Home page (divinedunlop.com): section 1 is not touched. Add the one block in release/1.0.0-home/01_home_teaser.html as section 2. Fine-Tuning carries the full module, so the home page stays light and Google indexes the module once.
